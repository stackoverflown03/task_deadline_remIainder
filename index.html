How to get a Google Client ID?
  1. Open the Google Cloud Console.
  2. Create a project, then go to APIs & Services > Credentials.
  3. Click Create Credentials > OAuth client ID (Application type: Web application).
  4. Under Authorized JavaScript origins, add http://localhost:8000.
  5. Enable the Google Classroom API and Google Tasks API in the API Library.
  6. Copy the generated Client ID and paste it above!
